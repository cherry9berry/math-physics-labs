# Lab 3.2: Euler-Bernoulli Beam (Balka)

## Work Description
This laboratory work investigates the **transverse vibrations of a thin elastic beam** modeled by the fourth-order **Euler-Bernoulli equation**. Unlike strings (wave equation), beams possess bending stiffness, which significantly complicates the mathematical description and boundary conditions.

The goal is to solve the beam equation analytically (finding frequencies and mode shapes) and numerically (using finite difference methods), then compare the results.

## Mathematical Model
The governing differential equation for a uniform beam:
$$EI \frac{\partial^4 u}{\partial x^4} + \rho A \frac{\partial^2 u}{\partial t^2} = 0$$
where $E$ is Young's modulus, $I$ is the moment of inertia, $\rho$ is density, and $A$ is the cross-sectional area.

### 1. Analytical Solution
Assuming $u(x,t) = X(x)\cos(\omega t)$, we get:
$$X^{(4)}(x) - \beta^4 X(x) = 0, \quad \beta^4 = \frac{\omega^2 \rho A}{EI}$$
*   **Characteristic Equation**: For a cantilever beam (fixed-free), the eigenvalues are found from $\cosh(D)\cos(D) = -1$, where $D = \beta L$.
*   **Eigenfunctions**: The mode shapes $X_n(x)$ involve a combination of $\cosh$, $\cos$, $\sinh$, and $\sin$ (Krylov functions).

### 2. Numerical Solution
A high-order **Finite Difference Method (FDM)** is used:
*   **Spatial discretization**: The 4th-order derivative is approximated by a 5-point stencil $[1, -4, 6, -4, 1]$.
*   **Boundary Conditions**:
    *   **Fixed end ($x=0$)**: Deflection $u=0$ and slope $u'=0$.
    *   **Free end ($x=L$)**: Bending moment $u''=0$ and shear force $u'''=0$.
*   **Solver**: An implicit scheme is implemented, solving a penta-diagonal system of equations using LU decomposition.
