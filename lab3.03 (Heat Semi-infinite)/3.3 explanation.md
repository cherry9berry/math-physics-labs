# Lab 3.3: Heat Equation in a Semi-Infinite Domain

## Work Description
This laboratory work focuses on the thermal evolution of a **semi-infinite rod** ($x \ge 0$). We model how an initial temperature $T_0$ throughout the rod changes when its boundary at $x=0$ is suddenly cooled or maintained at a different temperature. 

The work explores the **similarity property** (self-similarity) of the heat equation and compares three complementary solution methods: analytical (erf-based), integral (Poisson), and numerical (Finite Difference).

## Mathematical Model
The 1D Heat Equation:
$$\frac{\partial U}{\partial t} = a^2 \frac{\partial^2 U}{\partial x^2}, \quad x > 0, \quad t > 0$$
*   **Initial Condition**: $U(x, 0) = T_0$
*   **Boundary Condition**: $U(0, t) = 0$

### Solution Methods
1.  **Analytical Method (Similarity Solution):**
    Using the similarity variable $\eta = \frac{x}{2a\sqrt{t}}$, the solution is:
    ```math
    U(x,t) = T_0 \cdot \mathrm{erf}\left(\frac{x}{2a\sqrt{t}}\right)
    ```
    where $\mathrm{erf}$ is the **Error Function**.
2.  **Poisson Integral:**
    For a semi-infinite line, the solution is represented by an integral over the source function (Green's function), often implemented using the **Method of Images** to satisfy $U(0,t)=0$.
3.  **Numerical Method (Implicit Scheme):**
    A stable implicit finite difference scheme is used to compute the temperature values on a grid. Because the rod is "infinite," the calculation domain is chosen large enough ($L \approx 3a\sqrt{T_{max}}$) to minimize "edge effects."
