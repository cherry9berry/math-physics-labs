# Lab 3.5: Poisson Equation in a Circular Domain

## Work Description
This laboratory work focuses on solving the **stationary Laplace or Poisson equation** within a circular domain. Such problems are common in electrostatics (potential distribution) and steady-state heat conduction (temperature distribution).

The goal is to calculate the internal field values based on a given distribution on the circular boundary using both analytical series expansion and Poisson's integral formula.

## Mathematical Model
The problem is defined in **polar coordinates** $(r, \phi)$:
$$\Delta u = \frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{\partial r} + \frac{1}{r^2}\frac{\partial^2 u}{\partial \phi^2} = 0, \quad 0 \le r < R$$
*   **Dirichlet Boundary Condition**: $u(R, \phi) = g(\phi)$

### Solution Methods
1.  **Analytical Method (Fourier Series):**
    If $g(\phi)$ is given as a trigonometric polynomial, the solution inside the circle (assuming $u$ is finite at $r=0$) is:
    $$u(r, \phi) = \sum_{n=0}^{\infty} r^n (A_n \cos(n\phi) + B_n \sin(n\phi))$$
    In this lab, for $g(\phi) = 3\sin(3\phi) - \sin(4\phi)$, the solution is simply $u(r, \phi) = 3r^3\sin(3\phi) - r^4\sin(4\phi)$.
2.  **Poisson's Integral Formula:**
    The potential at any point $(r, \phi)$ inside the circle can be expressed through the boundary values $g(\theta)$:
    $$u(r, \phi) = \frac{R^2 - r^2}{2\pi} \int_{0}^{2\pi} \frac{g(\theta)}{R^2 - 2Rr\cos(\theta - \phi) + r^2} d\theta$$
    This formula effectively acts as a "smoothing" kernel, where the boundary influence is weighted by the distance to the point.

## Implementation & Results
The notebook `3.5 Poisson Circle.ipynb` evaluates the integral numerically and compares it with the analytical derivation. Both methods yield identical results (error $< 10^{-10}$), confirming the validity of the integral representation. The 3D surface plot visualizes how the boundary oscillations decay as we approach the center of the circle.
