# Lab 3.1: Wave Equation (Numerical Methods)

## Work Description
This laboratory work is dedicated to the **Numerical Solution of the Wave Equation** using **Finite Difference Methods (FDM)**. While Lab 2.10 focused on analytical solutions, this work explores how to implement stable and accurate computation schemes to model wave propagation in discrete space and time.

The primary objective is to implement, compare, and analyze the stability of **Explicit** and **Implicit** finite difference schemes.

## Mathematical Model
The 1D wave equation:
$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$$
where $c$ is the wave speed.

### Numerical Schemes
1.  **Explicit Scheme ("The Cross"):**
    Uses a 5-point stencil across three time layers. It is conditionally stable.
    *   **Stability Condition (Courant–Friedrichs–Lewy):** $r = \frac{c \cdot \Delta t}{\Delta x} \le 1$.
2.  **Implicit Scheme (T-Scheme):**
    More computationally expensive as it requires solving a system of linear equations at each time step, typically using the **Thomas Algorithm** (Tridiagonal Matrix Solver). It is unconditionally stable.

### Solution Algorithm
1.  **Grid Generation**: Discretizing space ($x$) and time ($t$).
2.  **Initial Step**: Special handling for the first time step $t_1$ using initial velocity $\psi(x)$.
3.  **Iteration**: Applying the difference stencil to progress through time layers.
4.  **Boundary Conditions**: Implementation of Dirichlet ($u=0$) or Neumann ($\frac{\partial u}{\partial x} = 0$) conditions on the edges.
5.  **Comparison**: Validating the numeric results against the analytical Fourier series solution.

## Implementation & Results
The notebook `3.1 Wave Equation.ipynb` implements both schemes. Results show that the explicit scheme produces "unphysical" oscillations if the Courant condition is violated, while the implicit scheme maintains stability but may introduce numerical dispersion. Simulations are visualized via **animations** of string vibrations.
